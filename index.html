Sheet 01 — About

Cloud infra now, AI/ML infra next

I lead a two-person cloud team as an independent contractor, currently engaged at Novo Nordisk, working across AWS and Azure. My focus is treating infrastructure as something you draft, review, and version — not something you click together by hand.

I'm extending that same discipline into AI/ML infrastructure: applying infra-as-code rigor to the systems that run models, not just the systems that run VMs. That's the throughline behind the Forward Deployed Engineer direction below — not a career pivot, an extension of the same practice.

  1. Now Cloud / DevOps Tech Lead — multi-cloud provisioning & golden-image platforms (AWS + Azure)
  2. In progress AI/ML-focused certifications
  3. Exploring Forward Deployed Engineer model — infra discipline applied directly inside client environments, with AI/ML systems in scope
